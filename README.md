# pilotarbuza.com

Сайт-визитка Максима Ахмадулина (pilot_arbuza). Статика без сборки: `index.html`, `404.html`, `assets/`.

- Портфолио и фото: https://pilotarbuza.ru
- Облако (Nextcloud): https://m.pilotarbuza.com

## Локально

```sh
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Деплой

GitHub Pages: `CNAME` указывает на `pilotarbuza.com`, `404.html` подхватывается
автоматически. В настройках репозитория включите Pages → Source: `main` / root.

## Структура

- `index.html` — все секции: точечное табло, имя и DEPARTURES, контакты, обо мне, маршрут, проекты, навыки, вершины, магазин.
- `assets/style.css` — палитра и шрифты в `:root`, адаптив в конце файла.
- `assets/main.js` — динамика: точки в hero, перещёлкивание табло, маршрут по скроллу, счётчики, карусели.
- `assets/img/` — портрет и текстура зерна.
- `shop/index.html` — отдельная страница магазина мерча (`/shop/`): пять принтов, у каждого пять расцветок, кнопки и форма предзаказа.
- `shop/<принт>/index.html` — страница каждого принта со своим превью для ссылок; собираются командой `python3 server/product_pages.py` из шапки `shop/index.html`, руками их не правят.
- `assets/shop.js` — каталог, страницы принтов, форма предзаказа и размерная сетка (массив `SIZES` — сейчас типовые значения, замените на замеры реальных футболок).
- `admin/index.html`, `assets/admin.js` — страница `/admin/` для управления предзаказами, вход по паролю.
- `admin/plan/`, `assets/plan/` — «План и CRM» (`/admin/plan/`): обзор, диаграмма Ганта, календарь, доска, контакты, команда. Вход тем же паролем, данные — в `server/crm.py`. На телефоне — экран «Сегодня» и нижнее меню; ставится на экран «Домой» и присылает уведомления (`server/push.py`).
- `me/`, `assets/me/` — личное приложение (`/me/`): главная со сводкой дня и брифом, заметки как на iPhone, «Страны» (копия Country Tracker: дни по странам, Шенген 90/180 и свои правила, импорт из фото, автоотслеживание через «Быстрые команды»), документы со сроками, деньги. Вход тем же паролем, данные — в `server/me.py`, ставится на экран «Домой». Контуры стран — `server/build_geo.py`.
- `server/` — сервис, который принимает предзаказы и проверяет пароль; установка описана в `server/README.md`. Без него форма и админка не работают.
- `assets/img/shop/` — мокапы футболок `<принт>-<расцветка>.webp` (900×840) и `og.jpg` для превью ссылки.

## Языки

Сайт открывается на английском; RU и TR переключаются кнопками в шапке (и в мобильном меню), выбор запоминается в браузере, можно открыть с `?lang=ru`. Все тексты лежат в `assets/i18n.js`, ключи совпадают с атрибутами `data-i18n` в разметке.

## Глобус и фото

- Города для глобуса — `assets/places.js`: одна строка на город, `wish: true` для списка желаний. Счётчики стран и городов считаются сами.
- Контуры суши — `assets/land.js` (world-atlas land-110m, упрощённые).
- Фото вершин — `assets/img/peaks/<гора>-1..3.jpg` (полноразмерные, до 1800 px) и `<гора>-N-t.jpg` (миниатюры 240×240).

## Что править

- Фото вершин помечены квадратными скобками; цен на сайте пока нет — идёт предзаказ.
- Слова в точечном табло — функция `linesFor` в `assets/main.js`.
