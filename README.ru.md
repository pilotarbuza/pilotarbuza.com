# pilotarbuza.com

[ [English](README.md) | Русский ]

Личный сайт Максима Ахмадулина (pilot_arbuza). Учусь на машиностроителя, пишу инструменты для автоматизации CAD, в остальное время занимаюсь авиацией.

Сайт состоит из статических файлов без сборки: `index.html`, `404.html` и папка `assets/`.

- Сайт: https://pilotarbuza.com
- Облачное хранилище: https://m.pilotarbuza.com

## Локальный запуск

```sh
python3 -m http.server 8080
# Открыть http://localhost:8080
```
